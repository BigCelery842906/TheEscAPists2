This is a mod the 'The Escapists 2' for use with Archipelago, the Multi World Randomiser. 

# Installing the APworld:
Download and install the way you usually would, no extra files required.

# Installing the mod:
Extract the zip into the root of your game directory, such that your Escapists2 folder looks like so:
- TheEscapists2 root folder
    - BepInEx (folder)
    - .doorstop_version
    - doorstop_config.ini
    - winhttp.dll
    - TheEscapists2.exe
    - (Other Escapists2 Files)


# How does The EscAPists 2 work for Archipelago?

Each prison gets randomised into the pool, putting checks for escapes, jobs, stats and random items into the pool0

## Locations:
Desks 

Job Checks 

Each Prison Escape 

Stat Checks (Strength, Stamina and Intelligence) 

## Items:
Certain Blueprints required for escapes

Progressive Stats

Prison unlocks

Random Items

## Goal Condition:
Set the number of unique escapes you must complete before you can goal

# Extra Features:
DeathLink - The DeathLink you all know and love

StealthLink - If you trigger a lockdown in your prison, everyone else with the setting enabled gets one too!

Payphone Hints - Pay some money into a payphone and you'll get a random hint!

# Future Features:
Favour Checks

DLC Prisons

Connecting via the game rather than the bridge
